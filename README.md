# ASP.NET MVC Learning Project

This repository contains my ASP.NET MVC project, developed while learning ASP.NET web development with C# and the .NET framework.

## Objectives

- Understand the Model-View-Controller (MVC) architecture.
- Learn how controllers, models, and views work together.
- Implement routing and form handling.
- Explore data validation and database connectivity.
- Practice building dynamic web applications.

## Technologies

- C#
- ASP.NET Core MVC
- .NET
- HTML and CSS
- Bootstrap
- SQL Server (if used in the project)
